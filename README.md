# -Languages-of-love-Comparing-romantic-novels
Sophie Accettola, Abby Toth, Maya March, Audrey Seymour, and Arwyn Logtens

Question: How does the language used to represent romantic relationships differ between 3 different romance novels?

Our dataset will be a collection of the following three novels found on Project Gutenberg: Pride and Prejudice (1813) by Jane Austen, Jane Eyre (1847) by Charlotte Brontë, and Wuthering Heights (1847) by Emily Brontë. Project Gutenberg is a digital library that makes older novels available to download.
